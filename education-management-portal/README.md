# Education Management Portal

A full-stack education management platform built with React + Vite (frontend) and Express + Firebase (backend).

## Tech Stack

- **Frontend:** React, Vite, React Router, Lucide Icons, Firebase Auth
- **Backend:** Express.js, Firebase Admin SDK, Firestore
- **Auth:** Firebase Authentication

## Getting Started

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
npm install
npm run dev
```

## Project Structure

See the file tree for full details. The project follows a clean MVC-like architecture with separate client and server directories.
